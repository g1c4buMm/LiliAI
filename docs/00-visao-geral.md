# Visão geral

O LiliAI é um ciclo de cinco comandos sobre um único arquivo, o `diario.json`.

| Comando | Movimento |
|---|---|
| `/liliai-entrevista` | **Conhecer**: uma vez. Gera a instrução do projeto e o diário inicial |
| `/liliai-sessao` | **Registrar**: depois de cada sessão. Notas, lições, ações, evidências e métricas |
| `/liliai-semana` | **Revisar**: toda semana. Atrasos, evidências da semana e pauta da próxima sessão |
| `/liliai-painel` | **Ver**: quando quiser. Painel HTML pessoal ou anonimizado para compartilhar |
| `/liliai-privacidade` | **Proteger**: antes de qualquer texto sair do Projeto |

## Princípios

- Sem código para quem usa. Comandos `/` ou prompts colados.
- Um arquivo, o `diario.json`, como fonte única. O painel é só uma forma de vê-lo.
- Medir resultado, não só esforço: ações contam o que você fez; evidências contam o que mudou em quem decide.
- Privado por padrão: modo Anônimo, a menos que você diga sim. Seus dados nunca entram no repositório.
- Todo número pode ser conferido: o painel calcula a partir do diário, sem digitação de totais.
